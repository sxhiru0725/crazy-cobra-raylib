# 🐍 Crazy Cobra — C + raylib

A classic snake-style game written in **C** using **raylib**.  
Features a start screen, pause, health system (3 lives), score, speed-up every 5 foods, and game-over with restart.

---

## 🎮 Features
- Smooth 2D movement on a grid
- Start, pause (`P`), and restart (`Enter`)
- Health system (wall/self collision reduces health)
- Speed increases every 5 points
- Sound effects on eat/game-over

---

## ⌨️ Controls
- **Arrow keys**: move
- **P**: pause / resume
- **Enter**: start / restart

---

✅ Notes
The window size is 960×720. Adjust inside main.c if needed.

Audio files must remain in resources/.

If you run from a different working directory, fix relative paths or pass cwd to match repo root.
